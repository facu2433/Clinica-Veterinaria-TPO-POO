# Clinica-Veterinaria-TPO-POO
Propuesta elegida: Clinica Veterinaria.
TPO POO - Clínica Veterinaria "Patitas"

Este es el repositorio con nuestra resolución del Trabajo Práctico Integrador, en el cuál realizamos un sistema en java para una clínica veterinaria; dueños y mascotas, turnos (con re-programación, urgencias y seña por ausencias), consultas de historia clínica, vacunas, stock con lotes, facturación, y reportes. Los datos se guardan en "clinica.dat" a través de serialización de objetos.

Requisitos: 
- JDK 11 o superior.

Instrucciones:
1) Clonar el Repositorio o descargarlo como zip.
2) Abrir la carpeta en el IDE (IntelliJ)
3) Ejecutar la clase "Main"

Datos de Prueba:
Al correr por primera vez no hay información cargada. En el menu, seleccione la opcion 8 ("Cargar datos de ejemplo"), esto carga:

- Precios de las atenciones.
- Dos veterinarios (Diaz y Gomez, que esta de guardia).
- Dos dueños, Ana Pérez (con plan de salud del 15%) y Bruno Ruiz, y cuatro mascotas.
- Productos con stock (Uno vencido y el otro con stock bajo).
- Un catálogo de vacunas.
